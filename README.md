# BankGuard AI

BankGuard AI is a banking fraud detection and
security monitoring platform built as a cybersecurity,
machine-learning and full-stack development
portfolio project.

## Goals

The platform will demonstrate:

- Transaction monitoring
- Fraud rule detection
- Machine-learning fraud detection
- Transaction risk scoring
- Login and device risk analysis
- Security alerts
- Investigation workflows
- Role-Based Access Control
- Security audit logging

## Stack

Frontend:
Next.js + TypeScript

Backend:
FastAPI + Python

Database:
PostgreSQL

Machine Learning:
scikit-learn

Deployment:
Vercel + API hosting + PostgreSQL

## Current Features

- Secure Next.js BFF authentication
- HttpOnly JWT session cookie
- Transaction monitoring dashboard
- Transaction filtering
- High-value transaction highlighting
- Cross-border transaction monitoring
